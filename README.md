# Годовой план тренировок

Реализация по [PRD.md](PRD.md): персональный конструктор годовой программы тренировок
для начинающих. Полностью клиентское приложение — один HTML-файл, без сервера,
без базы данных и без сохранения данных между сессиями.

## Запуск

Просто открыть [index.html](index.html) двойным кликом в браузере (Chrome, Firefox,
Safari, Edge) — интернет нужен только для загрузки шрифтов Google Fonts, вся логика
работает локально.

## Что реализовано (по разделам ТЗ)

- **6.1 Профиль** — рост, вес, возраст, пол, цель, сон; вводятся в форме слева,
  расчёт и план запускаются кнопкой «Рассчитать план» (после первого расчёта
  изменение отметок травм сразу обновляет план без повторного нажатия).
- **6.2 Травмы** — 5 зон (колени, спина, плечи, запястья, голеностоп), схема тела на
  SVG подсвечивает отмеченные зоны, упражнения в плане автоматически заменяются на
  щадящие аналоги (вес тела) с пояснением причины.
- **6.3 Расчёты** — ИМТ с классификацией, калории по формуле Миффлина — Сан Жеора
  (коэффициент активности 1.375, корректировка ×0.85/1.10/1.0 по цели), белок
  1.6–2.0 г/кг, обратная связь по сну относительно нормы 7–9 часов.
- **6.4 Годовая программа** — 6 этапов по 2 месяца, переключение без перезагрузки,
  диапазон повторений и акцент по кардио в каждом этапе меняются в зависимости от
  выбранной цели. Для упражнений со свободным весом (присед, тяга, румынская тяга,
  жим, выпады, подъём на носки) план показывает ориентировочный рабочий вес —
  формула `вес тела × коэффициент упражнения × коэффициент пола × прогрессия этапа`,
  округлённая до шага снаряда; вес нарастает от этапа к этапу (прогрессивная
  перегрузка) и не считается для упражнений с весом тела и для тестовой недели.
- **6.5 Техника** — подсказка под каждым базовым упражнением и под каждой заменой.
- **6.6 Питание и витамины** — общие советы по питанию, справочный список из 7
  витаминов/микроэлементов с ролью каждого и текстовым акцентом, зависящим от цели,
  без указания дозировок.
- **6.7 Сравнение до/после** — 5 показателей, автоматическая дельта, цветовая
  индикация с учётом направления показателя (для веса — нейтрально).
- **6.8 Дисклеймер** — постоянно видимый текст о справочном характере расчётов.

## Нефункциональные требования

- Без сервера, БД, localStorage/cookies — ввод живёт только в рамках вкладки.
- Адаптивная вёрстка: брейкпоинты 860px и 640px.
- Без сторонней аналитики/трекинга.
- Интерфейс и рекомендации — на русском.

## Структура проекта

## Вне скоупа v1 (см. PRD, раздел 11)

Регистрация/авторизация, сохранение прогресса между сессиями, напоминания,
видео техники, точное меню питания, дозировки витаминов, мультиязычность.
